## CEPFinder
CEPFinder is an AI-Powered app that helps users find top rated blue collar professionals(carpenters, electricians and plumbers) in their locality.
It allows users to select their city, locality and required profession and then uses Google Gemini AI to generate a comprehensive list of highly rated professionals.

## Features
* Find carpenters, electricians, and plumbers
* Location-based search by city and locality
* User-friendly interface built with Flet
* Error handling for network and service issues
* AI-powered recommendations using Google Gemini
* Scrollable professional listing with ratings and contact number

## Technologies Used
* Python
* Flet
* Google Gemini API
* JSON
* dotenv

## How It Works
1) User selects a city.
2) Major localities of the selected city are loaded.
3) User selects a profession.
4) CEPFinder sends a request to Google Gemini.
5) Gemini generates a comprehensive list of top rated professionals.
6) Results are displayed in a table.

## Disclaimer:
CEPFinder uses AI-generated recommendations based on publicly available information.
Some of the results might be wrong or outdated.
Users are recommended to verify the information before hiring the selected professional.
